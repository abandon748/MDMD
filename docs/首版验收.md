## 命令与证据

先按 [开发与换机指南](开发与换机指南.md) 配置环境，在工程根目录操作。调试程序的桌面验收入口为 `npm.cmd run test:ui`。

发布版验收使用实际构建的 MDMD 程序：

```powershell
npm.cmd run package
if ($LASTEXITCODE -ne 0) { throw 'MDMD packaging failed' }
powershell.exe -NoProfile -File tests/release-artifacts.ps1
if ($LASTEXITCODE -ne 0) { throw 'MDMD artifact verification failed' }
$env:MDMD_TEST_EXE = '../../release/MDMD.exe'
try {
    node tests/app.test.mjs
    if ($LASTEXITCODE -ne 0) { throw 'MDMD desktop acceptance failed' }
} finally {
    Remove-Item Env:MDMD_TEST_EXE -ErrorAction SilentlyContinue
}
```

测试会操作真实窗口与原生对话框；临时文档、应用数据和截图保存在 `test-results/` 下，不进入源码仓库。安装器专项 `node tests/installer.test.mjs` 仅在专用环境运行，发现已有 MDMD 安装登记时会拒绝执行。

## 验证边界

本次整理不对断电、磁盘物理故障、网络共享盘、云同步目录、长期输入压力及所有 Windows 设备作通过承诺。当前支持可选自动保存，但不提供崩溃草稿恢复；正常退出仍应确认内容已保存。具体功能范围见 [项目说明](../README.md)。
