## 运行

双击发布目录中的 `MDMD.exe`（源码打包输出到工程根目录的 `../../release`；目录布局见开发指南）。可用「打开文件」或 Ctrl+O 打开文档，也可把 `.md` 文件拖到 EXE 图标上，以命令行参数打开。本版支持手动配置 .md 文件关联与资源管理器右键菜单，不提供窗口内拖放。

无文件参数启动显示首页；打开成功进入阅读页，取消或失败保留原页面。文档工具栏的「首页」可返回，未保存修改需先选择保存／不保存／取消。空白文件仍进入文档页。首页关联管理与通用设置的系统集成共用状态。首页采用独立工作台布局，右侧工作笔记为静态排版示意。

首页「新建 .md」或 Ctrl+N 先弹出系统保存框，中文界面默认名为「未命名.md」，英文为「Untitled.md」。选择名称和已有目录后创建空 UTF-8 文件（无 BOM，后续默认 LF），进入分屏编辑；输入后需 Ctrl+S 保存。省略扩展名自动补 `.md`，其他扩展名拒绝，`.MD` 也可用。重名不会覆盖或自动编号，即使系统框询问替换并选择“是”，应用仍拒绝并提示重新选择。取消不创建文件、停留首页，失败可重新点击新建。文档页「新建」及 Ctrl+N 继续创建内存草稿，首次保存时再选位置。

需要 Windows x64 与 Microsoft Edge WebView2 Runtime。WebView2 需 130 或更新版本；EXE 不捆绑浏览器运行时。当前发布未做代码签名。

## 打开文件夹

首页「打开文件夹」弹出系统目录选择器。取消留在首页；读取失败提示原因，可重新选择。成功后进入左侧「文件」栏，列出直属的 .md/.markdown/.mdown 文件（扩展名不区分大小写），按名称排序，不自动打开首个文件。点击文件开始阅读，当前文档标记为「当前」，可切换「目录」查看大纲；切换时仍有未保存修改保护。

空目录显示「此文件夹为空」；只有其他文件或子目录则显示「此文件夹中没有 Markdown 文件」。尚未选择文档时不显示编辑器、保存按钮不可用，可以返回首页重选或使用「打开文件」。.txt 仍可单独打开。列表不递归、不包含链接，文件失效或编码不支持时保留当前文档并提示。

目录排在文件前，单击进入；「↑ 返回上级」逐层返回，到本次选择的根目录禁用。浏览目录只更新左侧列表，保留当前正文与未保存编辑；点击另一文件才询问保存／放弃／取消。导航失败保留原列表和正文，可重试。选择器可取消；子目录读取没有中途取消按钮。

文件栏目录名右侧的「⌖ 定位当前文件」会显示文件所在目录，滚动并聚焦当前行。根目录内文件保留原边界；单独打开或另存到根外的文件，以所在目录作为新根。无已保存文件时禁用；文件被删除或变为链接时提示失败，不覆盖草稿。单独打开的 .txt 定位后作为当前文件例外列出，其他 .txt 仍不显示。

每次进入、返回或定位都会重新读取该层；目录不自动监视、不递归扫描。返回首页或独立打开／新建文档结束目录会话，重启不恢复。链接目录不可进入。文件栏新建仍待后续开发。

## 历史记录

首页导航或文档左栏「历史」进入列表，按本机日期显示今天、昨天和 YYYY-MM-DD；最近成功访问在前，最多 100 条。完整路径不区分大小写去重，同名但不同目录分别保留，悬停查看路径；当前文件显示蓝色「当前」。重启保留记录，未打开文档时没有当前标记。

点击条目重新打开，沿用保存／不保存／取消保护；点击当前文件不重新加载，也不更新时间。成功打开、创建落盘文件或可编辑副本、首次保存或另存到不同路径更新历史；普通保存、重载、浏览目录、内存新建、取消和失败不更新。失效文件保留条目及原正文／草稿，显示原因，恢复文件后再次点击重试。

历史由 Rust 保存到 Tauri 应用数据目录（Windows 默认 `%APPDATA%/local.mdmd.markdown/history.json`），只存路径与时间。写入失败时文件仍正常打开，本次会话历史保留，历史栏显示警告和「重试保存」。损坏或未知版本记录保留原文件并暂停持久化；备份后修复记录，再重启恢复加载。清理该目录会清除历史；当前不提供删除、清空或多进程合并，同时运行多个实例时最后写入者生效。

## 收藏

首页导航或文档左栏「收藏」进入列表，空列表显示操作提示。上方按钮收藏当前文件／当前浏览目录，已收藏时可取消；未浏览目录时使用当前文件父目录。文档标题或预览右键可收藏当前文件／所在目录，文件栏右键收藏当前浏览目录；菜单可用上下键、Enter、Esc，点击外部取消。未落盘草稿不能收藏为文件。

按类型和规范化完整路径去重，Windows 不区分大小写，同名不同目录分别保留；加入时间倒序，重复添加及重新打开不改变顺序。最多 1000 条，不自动淘汰。文件和目录有不同标识，悬停查看完整路径，当前文件标记为「当前」。逐项 × 取消收藏，只移除记录，不删除文件／目录，不关闭当前文档。

收藏文件重新打开沿用保存／不保存／取消保护，点击当前文件不重载；收藏目录打开后成为新的导航根，不自动打开文件，不替换当前正文或草稿。没有文档时显示选择／空目录状态。失效路径保留收藏，显示错误；恢复后再次点击重试，或直接取消收藏。

原生端保存到应用数据目录的 `favorites.json`，与历史及设置分离。新增／取消只在写入成功后更新列表；失败保留原状态，修复存储后重复操作即可。损坏或未知版本保留原件并暂停变更，需备份、修复后重启。多实例不合并，最后写入者生效；当前没有收藏导入导出、自动清理或阅读位置恢复。

## 分级大纲

“目录”标签显示 H1–H6 标题层级；跳级标题挂到最近的较高层级下，不补虚拟标题。无标题显示空状态，空标题显示“无标题”。同名标题分别保留，悬停可看层级与源码行，点击各自跳转；格式标记不显示在标签文字中。

箭头展开／折叠子项，标题文字只跳转正文；可用 Tab、Enter／Space 操作。折叠不影响正文，预览滚动时蓝色标记跟随当前标题；当前标题位于折叠分支内时，祖先箭头显示蓝色提示，不自动展开，也不抢焦点。阅读与分屏均以预览位置为准。

同一文档的标题层级及文字序列不变时刷新保留折叠，段落增删后更新跳转行号；标题结构变化或切换／重载文档时重置展开。无自动预览的大文本先显示手动刷新提示，避免旧大纲误跳。不保存大纲状态到磁盘。

## 界面语言

在“设置 → 通用 → 语言 / Language”选择跟随系统、简体中文或 English。默认跟随 Windows 界面语言：中文界面用简体中文，其他语言用 English；不是跟随输入法或地区。启动及空闲窗口重新获得焦点时检查，手动选择不跟随。选中后即时保存，正常重启保留；关闭／Esc 不撤销已保存选择。

语言只改变应用界面、提示和程序指定的文件对话框标题；英文新建建议 Untitled.md，已有名称不改变。文档内容、文件名／路径、CSS、字体及自定义配色名称不翻译，草稿、撤销及大纲折叠保留。Windows 对话框内置按钮沿用系统语言；底层文件系统诊断和启动错误框可能仍为中文，不是全文翻译工具。

保存失败保持原界面和记录，尝试恢复原生会话；提示后可重新选择或重启。语言字段由 schema 11 引入；当前 schema 16 保留 language，旧 schema 1～10 读取补跟随系统且不回写，显式修改才升级；未知版本保留且禁止修改。清理 WebView2 profile 会丢失偏好，不支持跨实例同步。

## 链接悬停预览

“设置 → 通用 → 链接悬停预览”默认开启。正文链接悬停约 400ms 或键盘聚焦显示卡片，网页显示标题与摘要，本地 Markdown 显示正文摘录；移入卡片继续阅读，离开、Esc、关闭按钮或切换文档收起。加载失败显示原因，可以重试；悬停本身不打开或修改文档，不新增历史／收藏；显式点击按下文“附件与链接”执行。

网页仅支持 HTTP(S) 的 HTML 元数据，直接发送匿名请求，不带 Cookie／登录信息，不使用代理或执行 JS，不加载图片与页面其他资源；IP、URL 查询参数仍会发给目标。重定向最多 3 次，不从 HTTPS 降为 HTTP；网页最多 1 MiB，不支持登录／代理／动态脚本页面的完整内容。关闭开关后不再发起悬停请求，已发出的请求结束后丢弃结果。

本地仅当前文档目录内（含普通子目录）的相对 .md/.markdown/.mdown 文件，UTF-8／BOM，最多 256 KiB；不读取越界、绝对或链接路径。当前文档锚点取内存草稿；重名标题取第一处，锚点不存在则提示并显示开头。空文件显示空摘录，失效文件修复后可重试。没有磁盘位置的草稿需先保存才可预览相对文件。

开关写入成功才生效；写失败恢复原值。schema 12 新增 linkPreview，旧 1～11 读取补开启但不改写，正常重启同 profile 保留；关闭设置不撤销已保存选择。预览结果不缓存、不持久化。

## 阅读与通用设置

首页或文档工具栏点击「设置」，也可按 Ctrl+,。布局按 mdview 的居中弹窗与五项左导航组织。「外观」提供跟随系统、浅色和深色，默认跟随系统并响应系统颜色变化；手动选择后不受系统变化影响。「通用 → 字数统计」控制文档右下角全文与选区统计的显示，默认开启。阅读偏好分别修改、即时保存，正常重启保留；关闭／Esc 返回原页面与焦点，不改变文档或主动保存草稿，全文和选区计数按下述口径更新。

设置保存在应用 WebView2 用户数据目录内的 localStorage（键 mdmd.settings），不写入 Markdown 或可执行文件所在目录。兼容旧 schema 1（字符数）、schema 2（主题）、schema 3（排版）、schema 4（导航显示）、schema 5（快捷键）、schema 6（目录排版）、schema 7（分栏／软换行）、schema 8（配色／圆角）、schema 9（正文 CSS）、schema 10（标题格式）和 schema 11（语言），补齐缺省设置但读取时不改写；下一次修改时升级为 schema 16，包含工具栏显隐、默认关闭的双击编辑、默认开启的任务删除线以及全部既有设置；兼容读取 schema 1～15。正常重启沿用同一 profile／origin；清理浏览器数据会清除设置。保存失败会恢复原值并提示；损坏记录暂用默认、不自动覆盖，修改设置可重试保存；不兼容版本的记录会保留，并禁用使用该记录的阅读设置控件；系统集成、图标与引擎资源各自管理状态，反馈草稿仅在内存。配色管理和正文圆角已接通；正文自定义 CSS 已支持；高亮、公式与图表采用范围见文末，图表容器沿用圆角；Mermaid 已提供简单流程图的节点／连线表单编辑，复杂图形使用源码。主题覆盖应用内容；Windows 标题栏装饰及系统选择对话框由系统管理，标题文字格式可在通用设置选择。

「通用」增加历史记录、收藏和文件栏三个显示开关，默认全部开启。历史／收藏首页入口同步隐藏，目录大纲始终保留；隐藏不删除记录，历史继续登记打开的文件。隐藏当前标签时，有文档回到目录，无文档选择页回首页；设置弹窗保持打开。重新开启只恢复入口。文件栏隐藏时，首页打开文件夹或收藏目录会引导到通用设置重新开启。写入成功才应用回退，失败保留原页面与勾选。不会保存或丢弃草稿；重新打开 EXE 沿用偏好。

「排版」提供以下设置，作用于阅读及分屏预览，源码编辑器字体与行号保持原有行为。

| 设置 | 默认 | 调整方式与范围 |
| --- | --- | --- |
| 正文字体 | 系统字体 | 常用名称建议或输入单个本机字体名，局部预览、应用、取消、恢复默认 |
| 代码字体 | 等宽字体 | 同上，作用预览代码块及行内代码 |
| 字号 | 100%（正文 16px） | 75%～200%，每次 5%，可恢复默认 |
| 栏宽 | 900 CSS px | 450～1600px，每次 50px，可恢复默认；窄窗口适配可用宽度 |
| 正文与目录间距 | 20 CSS px | 0～80px，每次 5px；侧栏与主内容区之间的留白，阅读及分屏共用 |
| 目录字号 | 100%（12 CSS px） | 75%～200%，每次 5%；仅调整大纲标题文字 |
| 目录箭头大小 | 100%（12 CSS px） | 75%～150%，每次 5%；点击区域固定 22×30px |
| 交换左右分栏 | 关闭 | 开启后分屏左预览、右源码；保持编辑区宽度比例，阅读模式不受影响 |
| 单回车换行 | 新用户开启；升级旧配置关闭 | 控制 Markdown 段落软换行的预览，不修改源码／保存换行格式 |
| 代码块行号 | 关闭 | 各块从 1 开始，空行计数，折行续行不另编号；不混入复制文本 |
| 代码块自动换行 | 关闭 | 关闭时块内横向滚动，开启时长代码折行 |

字体名最多 80 字符，不接受字体列表或 CSS 语法。未安装或缺字时使用系统／等宽回退字体，不下载字体、不枚举全部系统字体；输入后先看样例，点击应用才保存，取消／Esc 保持原值。保存失败保留旧值并可重试。

阅读及分屏共用 1.8 倍正文行高（代码 1.7）、H1–H6 分级和圆角表格／代码块，字号同比缩放标题及正文内容。栏宽是含内边距的最大宽度，不是侧栏宽度；宽表仍在自身滚动，图片适配正文。设置不保存 Markdown、不重建编辑状态，保留草稿、撤销和大纲折叠；排版重排保留滚动像素位置并限制在新高度内，不保证同一文字在屏幕原位置。设置打开期间暂停双向滚动同步。默认值和步长是 MDMD 工程参数，不代表 mdview 出厂值。目录三项均可逐项恢复默认，不影响层级、折叠、跳转和当前标题跟随；长标题省略、悬停可看完整提示。间距不改变侧栏宽度，分屏时位于侧栏与靠左面板之间；正文内边距与居中留白另计。交换分栏只改变视觉位置，不重新创建编辑器；分隔条拖动和左右方向键仍按屏幕方向工作，比例是编辑区所占百分比，重启仍使用 50%。Tab 保留原有控件逻辑顺序。

## 字数及选区统计

右下角无选区显示「字数 N」，选中预览正文显示「选中 N · 全文 M」，选中编辑器源码显示「源码选中 N · 全文 M」。开关同时控制三种状态，数字与选区不保存到设置。

全文与预览选区统计渲染文本的非空白 Unicode 码点数：中文、英文字母、数字、标点和代码均计入；不计 Markdown 标记、链接地址、图片替代文字、列表序号和显示行号。不按英文单词分词；普通代理对 emoji 算 1，组合字符和 ZWJ emoji 按多个码点计数。空文件为 0，欢迎提示不计入。

预览选区须完整处于正文内，可跨段落／表格／代码、可反向选择；空白选区为 0，跨侧栏／工具栏不统计。分屏编辑器拥有焦点时统计所选原文，包括 Markdown 语法，多选区相加；不与渲染后的全文强行等同。取消选择或进入设置时显示全文，阅读模式不显示隐藏编辑器的选区。

编辑后先显示「待刷新」，随现有预览刷新更新内存草稿的全文数，保存／撤销／重做沿用相同口径。超过自动预览阈值的文档需手动「刷新」，刷新前不沿用旧数字，但源码选区可照常统计；大文档另存为导致预览清空时同样需刷新。统计不修改原文件，不新增设置字段。这是 MDMD 采用方案，不代表 mdview 算法实测。

## 快捷键方案

“设置 → 快捷键”提供 MDMD 默认、Typora、Obsidian 三套方案，覆盖当前二十二个动作。三套插入表格默认 Ctrl+T；Typora 方案将重做设为 Ctrl+Shift+Z、就地编辑设为 Ctrl+/；Obsidian 方案另用 Ctrl+E 进入就地编辑，三套阅读／分屏切换均为 F3，其他映射见上述默认表。这是 MDMD 采用的兼容方案，不是其他产品完整官方默认清单。格式动作见文末；应用全屏及整体侧栏隐藏尚未实现，暂不分配。

点击动作右侧键帽后录入。支持 Ctrl（可加 Shift）加字母／数字／ASCII 标点，以及 F2–F4、F6–F10；按键按键盘字母／符号位置识别。Backspace 恢复当前动作的方案默认，Esc 取消且不关闭设置，Tab 退出录入。切换方案、设置页或关闭弹窗也会取消录入。IME 组合、AltGraph、按住重复不触发命令或改键。普通文字、剪贴板、导航及系统／编辑器保留键不能分配；冲突显示具体动作，不交换或覆盖他人绑定。恢复默认若与另一自定义冲突，也须先解开冲突。

每套方案分别保存自定义项；切换后再回来仍保留。保存成功后才生效并更新首页键帽、按钮提示和空文档帮助；失败保留原值和草稿，可重试。配置保存到同一 profile 的 mdmd.settings（schema 13），重启恢复，不修改 EXE 或 Markdown；旧 schema 1～11 读取不回写，首次显式修改升级。删除／清理 WebView2 profile 会丢失自定义。

撤销／重做作用于获得焦点的可编辑源码；原生输入框保持自身文本撤销。首页只执行打开／新建／设置，无文档选择页只执行打开／设置；设置弹窗录入不穿透到文档。改键不会重建文档或清空撤销记录，旧托管键不再触发原动作。需要恢复入口时仍可点击设置按钮。

## 保存约定与恢复

编辑内容先在内存保留；默认**需主动保存**，可在通用设置开启自动保存已有文件（见文末说明）。当前没有崩溃草稿恢复。正常关闭窗口会提示未保存修改，断电、进程被强制结束时尚未保存的内容可能丢失。

保存已有文件时，先检查磁盘内容 SHA-256 与打开/上次保存时是否一致，再在同目录新建唯一临时文件，写入并 `sync_all`，复核原文件后通过 Windows `ReplaceFileW` 替换。新文件使用不覆盖现有目标的 `MoveFileExW`。UTF-8 BOM、有无结尾换行、LF 或 CRLF 会保留。没有修改时不重写原文件。

每次成功替换的旧文件保存在原目录 `.mdmd-backups/<文件名>-<UUID>.bak`，可复制为 `.md` 后打开恢复。备份不自动清理，按需要手动归档或清理。备份目录不可写时整次保存停止，不跳过备份。失败的 `.mdmd-<UUID>.tmp` 留在原目录，可作为恢复线索；界面保留未保存状态与当前内容。

旧版 `.moye-backups` 和 `.moye-*.tmp` 原地保留，不自动搬移、合并或删除；需要恢复时先复制成新的 `.md` 文件再打开。新版本只把新备份写入 `.mdmd-backups`。应用标识从 `local.moye.markdown` 改为 `local.mdmd.markdown`，使用独立 WebView2 数据目录；原墨页没有需迁移的设置／历史数据库，本轮基础设置在 MDMD 数据目录中新建，用户 Markdown 文件仍在原位置。图标沿用不含旧品牌文字的通用文档图案。

磁盘文件被其他程序改写或删除后，应用停止覆盖，提供重载与另存副本。检测在保存时强制执行，另外每两秒检查一次用于提示。外部程序不受本应用控制；哈希检查与系统替换之间仍有很短的竞争窗口，系统替换时被换下的版本会写入备份。此机制不承诺跨程序事务或所有存储介质上的断电原子性。首版验证环境为本机 Windows；网络共享盘、云同步目录需要补充验证。

## 首版范围

- 单窗口、单文档；UTF-8，文件上限 20 MiB。非 UTF-8 拒绝打开；混合换行或单独 CR 默认只读展示，避免静默改写格式；可明确确认备份后统一原文件换行并编辑。
- 超过约一百万 UTF-16 代码单元的文本不自动预览，可手动点击「刷新」。大文档解析仍在界面线程上，后续可迁移 Worker。
- 图片只允许文档目录内（含子目录）的 PNG/JPEG/GIF/WebP/AVIF/BMP，单图上限 10 MiB。远程图片、SVG、原始 HTML 暂未开放；网页及目录内 Markdown 链接可按下文规则显式打开。
- 不含所见即所得块编辑、数学公式、Mermaid、PDF 导出、多标签、文件关联或安装器；三种主题已在 DEV-03 阅读子项加入。

## 分栏与单回车换行

“设置 → 排版”增加交换左右分栏和单回车换行两个复选框，保存成功后生效，写入失败恢复原勾选与内容。单回车换行开启时将普通段落、引用和列表中的软换行显示为换行；关闭时恢复原解析规则。空行仍分段、双空格或反斜杠硬换行仍换行，代码块保留源码；不改编辑器 Enter、源文件和 LF／CRLF。

旧 schema 1～6 升级保留旧解析行为（单回车换行关闭），新用户／无配置默认开启；旧配置读取不回写，修改任一设置才写完整 schema 13。普通文档切换后按当前草稿重渲染预览，原预览选区失效、统计更新；源码选区、撤销与大纲折叠保留。大于原自动预览阈值的文档仍显示待刷新，点击“刷新”后采用新规则。排版重排保持受新高度约束的滚动像素，不保证文字锚点位置。

专项命令 `npm run test:split-breaks` 使用 `tests/split-breaks.test.mjs` 核对分栏几何、拖动／键盘／同步、软硬换行、草稿保留、旧数据迁移／异常与重启，串接此前全部桌面回归。


## 配色管理与圆角风格

“设置 → 外观”默认使用原浅／深色配色和 8px 圆角，选择“直角”使用 0px。圆角影响正文表格、代码块及图表容器，不改变控件、普通图片、行内代码和引用；图形节点本身的形状由 Mermaid／markmap 源码与引擎决定。

配色下拉可直接切换已保存方案；“管理…”可复制默认或自定义方案、修改名称及浅／深色各 13 项颜色、删除自定义方案。默认只读，最多 20 个自定义方案，按创建顺序显示；名称 1～40 字符、无首尾空格／控制字符、忽略大小写去重。复制、编辑、删除全部在点击“应用”后统一保存并选用当前方案，取消／Esc 放弃本次改动。删除当前方案并应用会回默认。

配色影响首页、侧栏、正文和编辑器通用色；语法高亮及警告／错误颜色继续跟随主题。设置和配色管理维持标准主题色，便于恢复低对比配色；可随时在外观下拉选回“默认”。跟随系统会使用方案的对应浅／深色颜色，不写入新配置。

保存于 mdmd.settings schema 12 的 appearance 字段，同一用户 profile 重启恢复。旧 schema 1～11 只在读取时补缺省字段、保留旧设置，显式修改才写新格式。保存失败不改变当前外观，配色管理草稿可重试或取消。设置只改显示、不保存 Markdown 或重建编辑状态。正文局部 CSS 见下节；不支持完整任意 CSS、在线主题或导入导出。


## 自定义 CSS

在“设置 → 外观”选择“编辑 CSS…”。默认关闭、内容为空，只影响阅读／分屏正文预览；不修改 Markdown，不影响首页、侧栏、编辑器或设置。普通选择器使用 h1、p、pre、table 等，正文根节点使用 .markdown-body，例如：

```css
h1, h2 { color: var(--accent); }
pre { border: 1px solid #888888; border-radius: 0; }
.markdown-body { line-height: 1.9; }
@media (max-width: 900px) { p { font-size: 18px; } }
```

编辑时是草稿；勾选“应用后启用”并点击“应用”，校验和保存成功后生效。取消／Esc 放弃修改。“恢复默认”清空草稿并关闭启用，仍须应用才保存。显示异常时，可直接取消外观页的“启用自定义 CSS”，原文保留，基础配色和排版恢复。

支持常用文字、颜色、尺寸、间距、边框、表格和列表排版属性、!important、现有主题变量引用及 @media；不支持外部资源、CSS 转义、变量定义、定位、动画、伪元素、嵌套选择器和其他 @规则。上限 32,768 字符、200 条规则、4 层媒体嵌套、单条选择器 1,024 字符。浏览器可能忽略未知声明或修复不完整语法；不是完整 CSS 检查器，也不能直接导入任意第三方主题。

CSS 可以覆盖正文默认排版和圆角；停用后回到基础设置。媒体查询跟随浏览器媒体条件，主题色可用 var(--accent) 等变量。CSS 隐藏文字不改变文档字数统计口径。

保存于 mdmd.settings schema 12 的 customCss:{enabled,source}，同 profile 重启恢复；旧格式读取不回写，显式修改才升级。保存失败保留旧效果和原记录，草稿可重试。结构有效但内容不可应用时，启动仅停用 CSS、保留原文及其他设置，进入编辑修正或恢复默认；字段类型／长度错误仍按坏配置保护。未知版本保留记录并禁用修改。没有跨实例同步或导入导出。


## 标题栏显示格式

“设置 → 通用 → 标题栏显示格式”提供“路径 + 文件名”（默认）与“仅文件名”。有文件时显示完整路径或文件名，并保留“— MDMD”后缀和未保存修改的“● ”前缀；无活动文档时为 MDMD，无路径草稿回退文档名。工具栏仍显示原有名称和完整路径，阅读／分屏共用格式。

选择后立即提交；原生应用成功后写设置，写失败回退原生标题、下拉与偏好并提示，原生失败不写存储。打开／关闭设置不写入；若标题恢复失败，按提示重选或重启。成功打开／编辑／保存／另存为和返回首页均沿用格式；取消文件操作保持原标题，不保存 Markdown 或清除撤销。

设置存于 mdmd.settings schema 12 的 titleFormat（path/name）。旧 schema 1～9 补默认 path（schema 10 保留原选择） 但读取不回写；下一次显式修改升级，其他设置保留。同 profile 重启恢复。坏记录保留原文并暂用默认，显式修改可修复；未来版本禁用修改。窗口启动读取配置前暂用默认格式，长路径由 Windows 裁剪，不承诺首帧无切换或跨实例同步。

## .md 文件关联与资源管理器右键菜单

MDMD 无需账号、注册或激活。这里的系统集成只配置当前 Windows 用户，启动时不会自动修改关联。请把程序放在固定位置，从首页关联卡“管理系统集成”或“设置 → 通用 → 系统集成”进入。

- **在 Windows 中选择默认应用**：配置当前 EXE 后打开 Windows 默认应用设置。点击 `.md`，选择 MDMD 并确认设为默认；若只显示设置首页，请搜索 `.md`。返回 MDMD 时自动检测，也可点击“刷新状态”。“待系统选择”表示候选配置已就绪，尚未检测为默认；只有实际打开程序匹配才显示“已关联”。关闭或取消系统设置不会改变默认应用，MDMD 不绕过 Windows 的用户确认。
- **旧安装图标修复**：升级时保留原安装目录，运行新版安装程序后，从已安装的 MDMD 打开系统集成，点击“修复关联并选择默认应用”。该操作补齐默认应用页面、打开方式选择器的应用名称／图标信息；自定义图标和恢复默认同步更新这些位置。程序启动不偷偷改注册表，已存在的另一份 MDMD 配置仍按所有权保护处理；不要从便携副本抢占仍存在的安装版配置。
- **旧路径已失效**：之前登记的 MDMD 已被移动或删除时，可点击“修复关联并选择默认应用”，将可确认归属的失效注册更新到当前程序。Windows 候选应用会登记 MDMD 名称及当前图标；最终默认选择仍需在系统设置确认。
- **解除关联**：如果默认仍为 MDMD，会先提示在 Windows 选择其他应用；切换后返回，再点击解除。默认未知时保留配置，避免留下失效打开方式。
- **右键菜单**：添加后可在 .md 文件的经典右键菜单中选择 MDMD；Windows 11 可能位于“显示更多选项”。删除菜单不会解除默认关联，两项独立。
- 点击动作立即执行；关闭弹窗只关闭界面。配置状态从 Windows 重新检测，不依赖界面设置文件。失败会尝试恢复已修改的值，并保留外来配置；不完整状态可重试。失效路径修复只接受所有权与命令一致的 MDMD 注册；另一份 EXE 仍存在、路径不可访问或注册被修改时继续提示冲突，不覆盖它。右键菜单与默认关联分别管理。
- 移动／删除 EXE 前先解除关联及菜单；程序不强改 UserChoice，不申请管理员权限。系统设置打不开时手动进入“设置 → 应用 → 默认应用”，搜索 .md。

本轮自动化在隔离注册表测试实际增删、回滚、冲突和重启；真实系统默认选择／Explorer 端到端仍待专用环境验收。逐值恢复不是断电事务，意外中断可能留下不完整配置。完整边界见开发资料中的 ADR-028／LIMIT-020。


## 应用图标

“设置 → 通用 → 应用图标”可更换或恢复默认。支持 ICO，最多 2 MiB，1～32 个方形图层，每层 16～256 像素；不支持直接选择 PNG、JPG、SVG。选择有效文件后立即保存并应用，取消不更改。图标复制到应用数据目录，之后删除或移动原图标不影响使用。

更新当前窗口／运行任务栏、首页与设置预览、已经配置的 MDMD 文件关联和右键菜单图标，以及当前用户下明确指向本 EXE 的可解析快捷方式。范围为桌面根层、开始菜单 Programs 最多 8 层及固定任务栏目录根层；其他用户、公共目录、其他 EXE 和无法解析的链接不处理。不新建快捷方式，不修改 EXE 内嵌图标。系统缓存可能延迟；其他已打开窗口需重启后读取新选择。

失败时尝试恢复窗口、系统图标和已修改快捷方式，错误信息留在设置页。出现“未完成”“丢失或损坏”时，先检查路径／权限，再点击“恢复默认”；坏记录会另存备份，高版本记录不会被覆盖。恢复默认保留已有文件关联和右键菜单。意外断电不保证恢复到旧自定义图标，需显式恢复默认。

选择保存在应用数据目录 appearance/icon.json，图标在 appearance/icons/，独立于阅读设置。最多保留 100 个图标，不自动删除仍可能被系统引用的文件。不要在仍使用自定义图标时清理该目录。实际用户桌面／固定任务栏的缓存刷新效果仍需人工核验。


## 渲染引擎资源管理

设置 → 通用 → 渲染引擎 → 管理，按需下载语法高亮、Mermaid、KaTeX 和 markmap 的固定版本。默认不下载；展示版本、进度、错误及重新检测／重新下载／取消。下载校验完整后才提交，失败或取消保留原有效资源；关闭弹窗继续下载，退出程序会中断。

“已就绪”表示资源通过完整性校验和隔离的合成样例加载检查，可离线重新检测。正文高亮、KaTeX 与 Mermaid／markmap 已按文末范围接入，文档语法仍可能单独失败；Mermaid 可视化编辑继续待办。资源保存在应用数据目录 engines 中；请勿手动修改缓存或标记。没有自动升级、代理设置和断点续传。固定资源清单维护在开发工程的 config/engines.lock.json，成品已内置该清单，发布包附第三方渲染资源许可。


## 本地问题反馈

反馈页顶部提供 MDMD 项目主页与复制链接，地址为 https://github.com/abandon748/MDMD。仅主动点击才请求系统浏览器打开，不自动检查更新、读取 Star 数量或发送反馈。浏览器调用失败可复制地址自行访问，复制失败可选中显示的地址手动复制。仓库由维护者管理访问权限；私有状态下无权限的用户无法访问，程序打开浏览器不代表仓库已公开。

设置 → 问题反馈中填写问题描述、复现步骤、期望与实际结果，预览内容后点击“复制反馈”或“导出 .md”，由你自行发送。问题描述必填；描述、期望、实际各最多 2000 字符，步骤最多 4000 字符。程序自动附带版本号；浏览器环境默认不附带，勾选后可在预览里核对。不会自动收集当前文档、路径、历史、收藏、日志或设备编号，不会在线发送。

关闭设置或切换类别保留本次窗口内的草稿；退出应用会清空，请先导出或复制。“清空草稿”只清本页，不动当前 Markdown。导出取消和失败都保留草稿；缺省扩展名补 .md，重名拒绝覆盖，即使系统先询问覆盖也不会覆盖原件，请换名后重试。复制失败可重试或导出。反馈文件保存为 UTF-8／LF，与编辑中的文档和撤销记录相互独立。


## 会话与保存状态

每个窗口只有一个活动文档。打开、重载、内存新建和返回首页建立新会话；保存／另存为保持会话和撤销记录。编辑先显示“正在同步编辑”，原生端确认最新版本后再判断是否有未保存修改。只刷新 WebView 时会取回已同步的内存内容，不能代替进程崩溃恢复；不要在同步失败时刷新或退出。

保存会等待编辑同步，保存／选择路径／确认离开期间暂时禁止编辑与切换。“已保存”表示当前缓冲区与最后成功确认的磁盘基线相同；文件可能随后被外部程序修改，后台约每 2 秒检查，不保证实时监控。磁盘版本变化显示冲突，不能覆盖原件，可另存副本或明确放弃后重新载入。无法读取磁盘时显示状态未知，不把检查失败当成未变化。

“编辑同步失败”时可直接重试保存，或缩减过大的内容后再试；失败不允许切换或关闭。“保存未确认”保留当前内容和错误原因，可重试保存或另存副本。即使一次保存已经落盘但回应丢失，也要重试确认；不会仅因为关闭错误提示就认定成功。另存为取消、未命名草稿选择保存后取消，都保留原会话和状态。切换／关闭时选择取消继续编辑，选择不保存只在目标操作成功后放弃；选文件后打开失败仍保留原草稿。

保存沿用 UTF-8、BOM／换行保留、内容哈希冲突校验、同目录暂存与备份。混合换行只读，文件属性／权限或备份目录阻止写入时保留草稿；修复后重试。原有恢复文件不可自行删除。会话、未落盘内容与撤销栈不会跨进程持久化；自动保存已有文件可在通用设置开启；自动恢复草稿及版本恢复入口尚未提供。

## 分屏与外部编辑

阅读与分屏切换时尽量保持当前预览块的位置，编辑内容、撤销和源码选区保留；双击预览正文可进入分屏并把光标定位到对应源码块起始行。链接仍按链接行为处理。分隔栏可拖动，左右键每次调整 2 个百分点，范围 25%～75%；Home／End 到边界，双击恢复 50%，拖动中按 Esc 或触发指针取消可回到本次拖动前的位置。比例与同步滚动开关仅保留在当前窗口，重启恢复默认。分栏交换和单回车换行仍使用原有设置。

工具栏“外部编辑”或默认 F4 调用 Windows 记事本；旁边的 ▾ 可选择自定义编辑器 EXE 或恢复默认。选择后立即保存，关闭弹窗不撤销，文件选择取消不改变原配置。只接受现存的绝对路径 `.exe`，拒绝当前 MDMD 自身；不支持脚本、快捷方式、命令模板或附加参数。直接启动进程并仅传入一个完整文件路径，不调用 shell 或 `.md` 默认关联。编辑器需要支持接收文件路径；启动成功不代表对方已完成打开或保存。

有未保存内容或尚无文件路径时，先提示“保存并打开”或“取消”。取消选择路径、保存失败或磁盘冲突均停止调用，保留草稿；成功保存后若编辑器启动失败，文件保持刚保存的内容，可修复路径后重试。调用本身不切换会话或清空撤销。只读文档可以交给外部编辑器，是否允许写入由该编辑器和系统决定。

外部修改通过约 2 秒检查及窗口重新获得焦点时的检查发现，提示后由你点击“重新载入”。不会自动替换当前缓冲区；存在草稿时仍需选择保存、放弃或取消。冲突时不覆盖磁盘版本，可取消后另存副本，或明确放弃草稿再重载；源文件删除、不可读或格式不支持时保留当前内容并显示错误。这里只提供冲突保护，不提供自动合并或跨进程锁。

编辑器选择单独保存于应用数据目录 `external-editor.json`（version 1）。保存配置失败保留原选择；配置损坏或版本不支持时保留原件并暂停修改／调用，备份修复后重启。丢失的编辑器可重新选择或恢复默认。同一窗口内的比例与阅读位置不写入该文件。

三套快捷键方案包含“外部编辑”，默认 F4，可各自修改。旧自定义若已经占用 F4，会保留旧动作，外部编辑自动使用空闲组合（优先 F6），实际组合显示在设置和按钮提示中。未改变既有设置格式或其他动作。

## 就地编辑

在阅读预览中右键目标块，选择“就地编辑”；也可先单击目标块，再点击工具栏“就地编辑”或使用快捷键。没有选定块时，选择当前可见的首个源码块。MDMD 默认／Obsidian 方案为 F2，Typora 方案为 Ctrl+/，可在快捷键设置中单独修改。旧自定义占用默认键时保留旧动作，新增动作使用空闲组合，以设置中的实际显示为准。双击正文仍进入分屏。

块内显示 CodeMirror 源码编辑器，周围内容保留为预览。标题、段落、列表、引用、代码块和表格按完整顶层块编辑；点击嵌套列表或单个单元格仍编辑整个列表或表格。使用解析器的起止行映射，不按标题文字查找，因此重名标题分别对应自身源码。保留块外文本、引用定义、缩进及现有 UTF-8 BOM／换行保存规则；这个入口是源码编辑，专用表格网格入口见下节。

输入先成为“就地草稿”，尚未写回文档。点击“应用并预览”、Ctrl+Enter 或再次按当前就地快捷键，将该块作为一次可撤销修改写回；取消按钮或 Esc 只丢弃本次块草稿，不回退之前的编辑。应用后焦点在工具栏就地按钮，可直接撤销／重做。输入法仍在组合时先完成输入再应用或离开；编辑器查找面板打开时，Esc 先关闭查找。

保存／另存、切换阅读或分屏、打开设置、刷新、切换文档或正常关闭窗口前先应用块草稿，然后执行已有同步、保存及离开确认。取消文件选择或取消离开会保留已经应用的未保存内容，不恢复为旧块草稿。磁盘冲突、保存失败或取消保存都不会丢弃文档内容；冲突时原件不被覆盖，可以另存副本，或明确放弃后重载磁盘版本。默认手动保存；开启自动保存后，已应用的主文档修改可自动保存到已有路径。

预览过期（例如大文档等待手动刷新）时拒绝用旧映射编辑，请刷新后重选。若编辑中发现文档基线已改变，拒绝应用并保留块草稿，请先复制，再取消重选。混合换行等只读文档不能就地编辑。没有可映射块的空文档或仅引用定义文档，以整个源码作为编辑范围。

块草稿仅存在当前 WebView 内存，强制刷新或进程终止可能丢失尚未应用的块草稿；应用后的内容继续遵守“会话与保存状态”的限制。块编辑本身不提供崩溃恢复或自动合并；自动保存不会强制应用块草稿。自定义 CSS 不直接匹配块编辑器内部元素，但对整个预览根的隐藏、透明或尺寸设置仍会影响其可见性；可用外部工具栏退出编辑并在设置中停用 CSS。

## 表格编辑

文档工具栏“插入表格”或 Ctrl+T 在当前正文块后添加一份草稿；分屏源码光标位于顶层空行时就在该空行插入：默认 2 列、表头 1 行、数据 2 行，空单元格，默认对齐。插入点前后补足必要空行分隔，保留原有内容；不替换当前选区。尚未闭合的代码围栏等会使插入不能成为顶层表格时拒绝插入，先修正源码再试。在已有预览表格上右键“编辑表格”可进入网格；右键“就地编辑”仍打开普通块源码。

网格单元格填写单行 Markdown 源码，例如 **粗体**、链接或行内代码的标记；不是富文本控件。输入普通竖线时自动转义为 \|，已有转义保留；不支持单元格真实换行、合并单元格或嵌套表格。点击单元格选择操作行列，支持上／下插行、删除行、上下移动行、左／右插列、删除列、左右移动列、拖动表头 ↔ 调整列顺序，以及默认／左／居中／右对齐。首行固定为表头，不允许删除或参与数据行移动；至少保留一列，数据行可全部删除。整表删除可用普通就地源码编辑。

“按当前列升序／降序”仅排序数据行，按单元格源码字符串比较，相同值保持原次序；不做数字、拼音或渲染文本排序，例如升序时 10 在 2 前。Tab／Shift+Tab 按行移动，首尾边缘离开网格，不隐式添加行。“展开／还原表格”仅在当前窗口内容区放大编辑块，不是 Windows 全屏；窄窗和宽表使用内部滚动，操作结果不随查看模式变化。

“表格源码”显示同一份 CM6 块草稿，“返回网格”重新校验。只接受规则的顶层管道表格：所有行列数一致，最多 200 数据行、50 列、10,000 单元格，单元格最多 4,096 个 UTF-16 单元，表格源码最多 262,144 个 UTF-16 单元。缺列、多列、嵌套、附带其他正文或无法解析的源码不会被截断或补齐。校验失败保留源码并禁止网格应用，请修正或取消；普通就地编辑仍可处理更广的 Markdown。

打开后直接应用或取消不会规范化原表格。实际修改会将本表格统一为带外侧竖线、单空格内边距、三短横分隔的源码，保留列对齐、单元格 Markdown、块前后空白和表格外所有字符；不承诺保留原有列宽空格。原文 BOM／CRLF／无尾换行规则继续沿用原生保存通道。

“撤销／重做表格修改”处理块草稿操作；源编辑区使用已有快捷键，网格输入框的 Ctrl+Z 沿用原生文本撤销。点击“应用并预览”或 Ctrl+Enter 将整表作为主文档的一次撤销事件；取消或 Esc 只丢弃这次表格草稿。保存、切换文档及正常关闭仍先应用，再执行既有同步与保存确认。输入法组合期间不应用；保存选择取消、同步失败或磁盘冲突都保留主缓冲，外部版本不会被自动覆盖。强制刷新／终止可能丢失未应用草稿。

新增快捷键沿用三方案自定义、冲突拒绝及重启恢复，当前沿用 settings schema 16。表格块草稿不单独持久化，自动保存等待用户应用；CSV 复制／导出留在输出阶段。


## 自动保存

在设置 → 通用开启“自动保存文档”，默认关闭。主文档停止修改约 1 秒后，已有路径的可写文档自动沿用原生保存通道写入；编辑、撤销、重做或应用块编辑都会重新计时。调度及磁盘耗时会推迟实际完成，不是定时硬实时服务。开关持久化，重启继续生效。

未命名文档必须先手动保存并选定路径，取消时保留内容，不会由计时器弹出文件窗口。就地／表格草稿先由你应用；草稿期间不自动应用、保存或取消。输入法组合、设置等弹窗及其他文件操作期间等待；组合结束重新计时。保存期间短暂锁定输入与切换，防止手动与自动保存并发；保存完成保留撤销历史。

外部变化、磁盘检查未知、同步或保存失败时暂停当前文档的自动保存，状态栏提示手动保存或重载。修复故障后请手动保存；冲突可以另存副本或明确放弃后重载。取消和失败保留内容，开关重开或继续输入不会不断重试。手动保存成功或进入新的文档会话后解除暂停。自动保存沿用备份机制，备份可能随修改增多；没有自动清理、跨实例写锁、崩溃恢复或断电保证。

设置升级至 schema 13，旧版本默认补关闭、不在读取时回写；损坏或未来设置保持原记录并安全关闭自动保存。软件旧版本不支持该设置记录，应使用兼容版本管理。自动保存不代替退出前的未保存确认。


## 格式工具

工具栏“格式工具”提供加粗、斜体、删除线、引用、代码、插入链接、列表循环、高亮、清除格式。分屏时处理源码选区；阅读时先进入当前块的就地源码。普通就地编辑只改块草稿，可应用或取消；表格专用编辑期间禁用格式菜单，单元格仍可直接填写 Markdown。仅处理单一源码选区，不转换浏览器的预览选区。

加粗 Ctrl+B，斜体 Ctrl+I，删除线 Ctrl+Shift+X，引用 Ctrl+Shift+Q，代码 Ctrl+Shift+反引号，链接 Ctrl+K，列表 Ctrl+L，高亮 Ctrl+Shift+H，清除格式 Ctrl+反斜杠。三套方案均提供这些默认组合，可独立改键；旧自定义优先，实际组合以设置显示为准。

行内标记可以再次操作解除；空选择会插入“文本”占位。引用及多行代码按完整行处理。列表按“普通 → 无序 → 有序 → Todo → 普通”循环，保留缩进，有序重新从 1 编号，混合类型转无序。链接插入示例地址并选中它供替换，不自动打开网页。高亮采用 ==文本==，在预览显示高亮，代码中的标记保持字面显示。

清除格式把选中的 Markdown 转为纯文本（没有选区时处理当前行），会去掉链接地址、表格结构和其他排版标记；选区外内容不变，操作可撤销。单次最多处理 262,144 UTF-16 单元，不支持多选区同时格式化；输入法候选未结束时先完成输入。查找面板已提供替换和全部替换，可直接使用并撤销。

格式操作通过同一 CM6 修改通道，不直接落盘；应用就地草稿后再参与主文档保存。默认手动保存，开启自动保存后沿用其延迟与冲突规则。


## 斜杠插入与内置片段

在分屏源码的顶层空行输入 /，或把光标放到空行点击“插入片段”。阅读模式先进入当前块的就地源码，再移到空行操作。可搜索并选择标题、无序／有序／任务列表、引用、代码块、表格、分隔线、链接共九种模板；模板预览只显示源码。向下键从搜索框转到列表，Enter 插入，Esc 取消。

取消保留已输入的 /，可用撤销移除；开启自动保存后，这个字符也会按普通修改保存。插入为一次可撤销编辑，就地草稿仍需应用，未命名文档仍需首次手动保存。链接示例地址需自行替换，不会自动打开网站。

片段仅在整行为空或只含 /、没有选区的顶层位置使用；代码、列表、引用、表格内部不触发。输入法组合时不弹窗，粘贴 / 不弹窗。当前活动源码缓冲最多 262144 UTF-16 单元；超过可手动输入 Markdown。没有自定义模板、变量跳转或图表／公式模板。插入前状态变化则提示取消重开，不将旧位置写入新文档。

## 附件与链接

先保存文档，再使用“插入图片”选择单张图片，或在分屏／普通就地源码编辑区粘贴剪贴板图片。支持 PNG、JPEG、GIF、WebP、BMP、AVIF，单张最多 10 MiB；复制到文档旁 assets，使用唯一文件名并插入相对 Markdown 引用，不上传服务器。插入可撤销，就地草稿可取消；已复制图片不会随撤销／取消删除。另存到其他目录不会自动复制 assets，需要保留相对目录结构。未命名、只读、表格网格或不支持的图片会拒绝插入。

点击正文中已加载的图片可查看，默认适应窗口，25%～400% 缩放，关闭或 Esc 返回。网页 HTTP(S) 链接交给默认浏览器；目录内 Markdown 链接在 MDMD 打开，继续执行未保存保护。支持标题／line-N 锚点，重名标题取首个；缺失锚点提示并保留已打开文件。本地链接／图片拒绝父目录、绝对／UNC／设备路径和目录联接；损坏或丢失图片保留替代文字，悬停显示失败原因。不支持 SVG、远程图片下载、任意文件附件／协议、拖放、多图片粘贴或 Wiki 链接。悬停预览开关不影响点击打开。

## 代码语法高亮

预览支持锁定 Highlight.js 11.12.0 的 36 个语言标识与自带别名。围栏标明 js、python、rust、c++、json、html 等语言即可高亮；无标签时在有限常用语言中自动识别，未知或不确定时保持纯文本。text 明确纯文本；行内 code 不染色。颜色随浅／深／系统主题切换，行号、折行、字体和复制原文保持原有行为。

首次只加载本地已安装资源，不自动联网。未安装时在设置 → 通用 → 渲染引擎下载；损坏／失败时修复后点刷新，重启也会重新检测。明确语言单块上限 65536 UTF-16 单元，未标语言 8192，一次最多 100 块且总计 262144；超限仍显示完整原文。异步结果不会改写文档或替换正在选择的代码块，后者可刷新重新高亮。公式与图表的独立范围见下文。


### 数学公式

正文支持 `$x^2$` 行内公式与独占行 `$$` 包围的块公式；反引号／代码块内不解析。美元与内容之间不要留空白，货币、转义和未闭合定界符保留普通文字。首次使用在“设置 → 通用 → 渲染引擎”下载 KaTeX，之后离线使用；不会因打开文档自动下载。缺失／损坏、非法 TeX 或超限时保留原文，悬停查看原因，修复后刷新。只影响正文预览，保存仍为原始 Markdown。

不启用外部资源或受信任 HTML 命令；跨公式宏定义、自动编号、外部 TeX 包不支持。单式 16384 UTF-16 单元、一轮 100 式／65536 单元，超限显示原文。公式完成后统计按实际 HTML 文本更新（不等于数学语义或视觉字形数）；源码选区仍按原文统计。


## 图表与脑图

使用 mermaid 或 markmap 围栏，先在引擎管理中下载对应固定资源，之后离线渲染。支持 Mermaid 锁定库的图形语法；markmap 将标题与列表转为静态脑图。默认适应宽度，可在 25%～200% 之间以 25% 步长缩放、查看源码、进入就地源码编辑；也可点击图片使用已有查看器。浅深主题更新后重新绘制，容器圆角沿用正文设置。缩放与源码展开只在当前预览有效。

图内链接、远程图片和外部脚本不启用；图表作为图片显示，图形标签不计字数，展开或失败的可见源码计数，工具栏不计。缺失／坏资源、语法错误、超限或图片解码失败均保留源码，可修复后刷新。单块 32768 UTF-16 单元，一轮最多 12 块／65536 单元；复杂图不是性能保证。流程图可点击“可视化编辑”：支持 LR/RL/TB/TD/BT、矩形／圆角／菱形节点、文字与有向连线。表单编辑后显示真实预览，源码和表单共享块草稿；应用一次写回，可整体撤销；取消保留正文。无操作不格式化，修改后只规范化当前围栏。复杂 Mermaid 类型、样式、子图、链式语法不转换，请取消后使用源码编辑。最多 100 节点、200 连线，标签最多 200 字符且不含标记字符。引擎缺失时仍可编辑源码，下载后恢复图形预览。

## HTML 导出

工具栏“导出”打开输出面板。导出当前内容（含未保存修改），可选择当前阅读样式或简洁浅色。图片、公式、图表需先加载成功；缺失／损坏／超限会提示修复后重试。为便于离线分享，采用单个 HTML，嵌入已验证图片、图表和公式字体，无在线引擎依赖。不会保存或改写 Markdown。

取消不生成文件；只接受 .html，缺扩展名自动补全；同名文件拒绝覆盖，请换名称。输出上限 50 MiB，超限／磁盘失败保留编辑内容。导出是静态快照，图形不可交互；链接地址保留原值，移动 HTML 后相对文档链接可能需调整。未安装的自定义正文字体仍使用系统字体回退。

## PDF 与打印

在导出面板选择 PDF／打印。默认 A4 竖向、15 mm 页边距，支持 Letter、横向及 5–30 mm（按钮步长 5 mm，可输入整数）。样式沿用当前／简洁选择，输出静态正文快照，不含目录和编辑界面。系统打印界面可选择另存为 PDF 或打印机，其纸张、缩放、背景图形等选项可能覆盖页面设置。返回应用只提示界面已返回，不冒称文件已保存或打印已完成。取消不改变原文，失败可重试。

## 复制与表格 CSV

导出面板可复制 Markdown 原文、HTML 源码或富文本。富文本同时提供纯文本，目标软件可能过滤样式／图片；权限失败可重试或改用文件导出。表格下拉按正文顺序列出顶层规则表格，CSV 保留单元格 Markdown 原文（含格式符号），双引号转义、逗号分隔、CRLF、UTF-8 BOM。取消不写、同名拒绝覆盖，表格为空或不能安全转换时拒绝。

## 历史版本恢复

工具栏“历史版本”列出当前文件旁 .mdmd-backups 和兼容 .moye-backups 的最近 100 个匹配版本（按备份修改时间倒序）。先选版本阅读源码，再“恢复到编辑区”；关闭取消，不删除备份。恢复整体可撤销／重做，只恢复内容，保持当前文件编码／换行设置；自动保存会暂停，需手动保存。保存继续检查外部冲突并备份当前磁盘内容。版本被改动、失效、非 UTF-8／混合换行、链接路径或当前会话变化时拒绝恢复，原内容保留；不是崩溃草稿恢复。

## 任务清单回写

预览中的列表任务框可直接勾选／取消，只替换源码对应标记字符；支持嵌套和引用中的任务。变更可撤销，保存沿用原通道，自动保存开关仍有效。代码块、普通文本中的 [ ] 不变；只读文档、旧预览和就地草稿中不能点击回写。导出使用静态 ☑／☐，不携带可修改控件。

## 扩展 Markdown

支持 ++下划线++（单行纯文本）、[^名称] 引用与 [^名称]: 内容 脚注（四空格／Tab 续行可包含多段和列表；最多 100 定义，重复定义保留普通文本；重复引用共享编号并有逐处回链）、NOTE／TIP／IMPORTANT／WARNING／CAUTION 五类 > [!类型] 提示块。Wiki 链接 [[文档|别名]] 自动补 .md，可带 #标题；![[图片.png]] 嵌入目录内位图。独占行 ![[文档.md]] 嵌入一层基础 Markdown，最多 10 项／每项 256 KiB；嵌入内引用不继续递归，图片和链接按被引用文件目录解析。嵌入内容只读，点击文件名可打开编辑，缺失／超限保留引用并提示刷新。不自动下载远程图片，不支持库级模糊查找、跨目录越界、块 ID／片段嵌入或嵌入内增强图表引擎。


## 正文搜索

阅读模式 Ctrl+F 或“查找正文”搜索当前已渲染文本，按字面不区分大小写；匹配跨行内强调但不跨段落，包含代码与已加载的嵌入文字，不搜索图片像素／图形内部／隐藏控件。Enter／Shift+Enter 或按钮循环跳转，Esc 关闭；刷新重新计数，切换文件清空，分屏 Ctrl+F 仍搜索源码。上限前 1 MiB 渲染文本／10000 匹配，超限明确提示；查询不持久化、不替换正文、不改变统计与撤销记录。

就地编辑普通段落／标题／列表／引用时，直接在排版文字中输入；先点正文中的位置再点击“就地编辑”，或双击普通文字块。编辑中点击其他正文块会先应用当前草稿，再打开所点块；Ctrl+Enter 应用，Esc 取消，Ctrl+Z／Y 撤销／重做。当前块可能规范化 Markdown 记号，块外源码保留。支持粗斜体、删除线、高亮、链接文字和行内代码；复杂内容沿用源码或专用工具。“源码编辑”可切换同一草稿，查找、图片／片段操作也可转到源码模式。粘贴按纯文本处理。

“设置 → 通用”可选择外部编辑器，并分别隐藏模式、外部编辑、格式、插入四组工具。隐藏不禁用功能／快捷键，设置及文件操作保留。显示偏好保存失败时恢复旧值。

“专注模式”隐藏顶部栏、侧栏、小工具栏和状态栏，分屏仍保留两栏。按 Esc，或鼠标移至窗口内容顶部点击“退出专注”，恢复界面和当前草稿；弹窗／查找先处理自己的 Esc。保存错误和磁盘冲突提示仍显示。专注状态不跨重启保存，不自动进入系统全屏。

2026-10-27 补充：代码块或切至“源码编辑”后，也可点击其他正文块切换编辑；会先校验并应用当前草稿，组合输入／无效表格／过期基线会保留草稿并提示。保存按钮默认普通样式，仅开启自动保存时持续高亮；高亮不代表已保存，具体结果仍看状态栏。

就地切换稳定性修复：列表等块的末尾分隔空行保持；点击代码正文进入编辑时按代码文字定位，不落在开头围栏前。若当前源码草稿使目标块无法再独立定位（例如未闭合代码围栏），程序保留草稿并提示先修正、应用或取消；不会静默结束编辑。磁盘冲突时本地切换不覆盖文件，保存／重载仍按原有冲突提示操作。

就地输入维护：普通块的撤销／重做同时恢复本次编辑前后的文字、段落和选区；中文组合提交作为一次输入撤销，空段与回车分段也能重做。组合输入尚未结束时不应用草稿；先提交或取消候选，再应用／保存。仍为单块编辑，块开头退格不删除其他独立块。保存冲突不会自动覆盖外部版本。

表格定位补充（2026-10-28）：阅读中先点正文块，分屏中以最近操作的源码光标或预览点位为准；列表、引用、代码块中的位置会落在整个顶层块之后。未点选时使用当前可见块，空文档从开头插入。就地编辑中的文字草稿先应用，再建立表格草稿；取消表格仍保留这些文字，可单独撤销。表格应用后需要手动或按已有自动保存设置写入磁盘。


图片／片段定位补充（2026-10-28）：分屏以最近点击的源码或预览位置为准。阅读点击文字后插入图片会建立该块草稿；就地排版可在文字光标／选区处插入，确认后显示包含图片语法的块源码，应用后仍需按既有方式保存。取消或图片无效时保留草稿和光标；成功插入可以规范化当前排版块，撤销恢复原写法，块外原文不变。复杂预览无法可靠定位时请在源码中选择位置后重试。片段仍仅在顶层空行或单独的 / 行插入，就地新建空段也可使用；在正文中间会提示，不会追加到文末。


格式定位补充（2026-10-28）：阅读、分屏预览中的同一块文字选区可直接使用格式工具；工具保留正向／反向选择，分屏源码按最近有效光标／选区操作。就地排版格式仍暂存于块草稿，应用后经原保存流程写入文件；撤销恢复文字与选区，删除线可正常重做。引用／列表沿用当前段落的块格式行为。跨独立正文块的预览选区需改用分屏源码；过期映射需刷新后重新选择，不会改到旧源码位置。

剪贴板维护补充（2026-10-28）：阅读／预览可复制文字，修改须在分屏或就地编辑中进行。就地排版粘贴按当前块内选区插入纯文本；只有 HTML、图片或空剪贴板时保留原文，不删除选区。复制和剪切沿用浏览器剪贴板操作，撤销／重做恢复编辑内容及选区；跨块修改使用分屏源码。图片仍可通过原插图入口或源码粘贴处理。块草稿继续需要应用／保存，外部文件冲突不会自动覆盖。

圆角预览补充（2026-10-28）：设置 → 外观的圆角选项下提供表格和代码块小样，随已保存的圆角／直角选项变化。此设置控制正文容器的边角，不改变按钮和设置窗口；正文自定义 CSS 若指定边角，可覆盖基础效果，小样仍展示基础选项。保存失败时小样与正文一起保留原值。

## 预览工具与兼容增强（2026-10-28）

- 网络位图：点击“加载网络图片”才联网，来源主机显示在旁；失败可重试，刷新／重新打开需再点击。支持无登录 HTTP(S) PNG/JPEG/GIF/WebP/BMP/AVIF，最多 10 MiB，不支持 SVG；不发送 Cookie、凭据或文档内容。同一时间只处理一个预览网络请求，忙时可稍后重试。完整导出需先加载图片，之后内嵌到 HTML，不自动写入源 Markdown。
- 表格上方新增“编辑表格”直观入口，原右键网格仍可用。只读、保存忙、已有草稿或预览尚未同步时禁用；先应用／取消当前草稿再操作。
- 普通代码块有“复制代码”和“行号”；复制不含行号，局部行号只在此次预览有效，刷新后跟随全局设置。代码块工具不用于 Mermaid／markmap；行号是屏幕辅助，不作为导出正文。
- 排版设置中“已完成任务显示删除线”默认开启，可关闭；只划完成项自身文字，不划穿子任务。开关自动保存，失败保持原值；当前样式 HTML 导出保留删除线。
- 五类提示块各有图标和配色，随浅深主题变化，普通引用不变；自定义 CSS 仍可覆盖正文。提示块使用源码编辑，避免把生成标题保存进 Markdown。
- 脚注支持多行／多段／列表与每处引用的返回链接；定义续行需缩进四空格或 Tab。未定义引用保留文字，脚注体不递归嵌入脚注或文档；导出保留回链。
- 简单 Mermaid 流程图新增画布：拖动节点、双击改字、选择矩形／圆角／菱形、复制／删除节点，Alt 拖到另一节点添加连线；双击连线删除，也可用原表单。语义修改共用撤销／重做，应用后仍需保存。拖动位置仅保留本次画布，应用后 Mermaid 自动排版；不保存自由布局。带子图的流程图和时序图可直接编辑能定位的标签，结构与样式声明可通过源码修改。

## 不另存：统一换行并编辑原文件

混合换行提示栏点击“统一换行并编辑原文件”，确认“备份并转换”后，程序在原路径写入统一 LF 的文本，保留 UTF-8 BOM；成功后进入分屏，重启后可继续编辑同一文件。取消或 Esc 不修改；外部变动、文件权限、备份或写入失败会停止，保留只读与恢复信息。此操作不由打开或自动保存触发。

转换前原始字节保存在同目录 .mdmd-backups，成功提示显示完整备份路径。历史版本可恢复正文，但不会恢复混合换行；需要字节级恢复时，先另存当前需要保留的修改并关闭文档，再把对应 .bak 原样复制回原路径。再次出现混合换行只读是原格式已恢复。格式转换不进入 Ctrl+Z 文本历史，转换后的编辑仍可正常撤销。只想修改副本时仍可用“另存为可编辑副本”。


## 在 Mermaid 图上修改文字

点击图表的“可视化编辑”。简单流程图中，双击节点即可在框内改字，选中节点后按 Enter 也可开始。形状、添加连线和拖动沿用画布工具。

时序图中直接点击参与者名称、消息文字或备注进行编辑。回车确认当前文字，Esc 放弃当前输入。点击“添加消息”后依次点发送方和接收方，点击“添加备注”后点对应参与者。新消息和备注追加在时序末尾。“应用并预览”把草稿写回当前文档，保存后才写入磁盘。

含子图、样式或链式连线的流程图也可点击能对应到源码的节点和连线文字。未提供点击区域的语法可从“编辑源码”处理。


## 编辑子图、节点归属和样式

打开流程图的“可视化编辑”。在简单画布里先点“子图与样式”，复杂流程图会直接显示这些工具。

- 点“新建子图”，在图上的输入框填写名称，按回车或点“应用到草稿”创建顶层子图。点击已有子图标题可原位改名，已有子图 ID 和引用会保留。
- 点“移动节点”，先点图上的节点标记，再点目标子图标题的标记。选择“移至顶层”可将节点移出子图。Mermaid 会根据新的归属重新排版。
- 点“节点样式”或“连线样式”，再点对应图形上的标记。节点支持填充色、边框色、线宽和线型。连线支持颜色、1 至 6 像素的线宽和实线、虚线、点线。每次选择一项，点“应用到草稿”预览。
- “结束选择”放弃当前工具选择。每个已提交的操作都可在块内撤销和重做。“应用并预览”提交整个块，“取消本次编辑”放弃整个块。保存后才写入磁盘。

移动支持能识别的节点声明、常见箭头和链式连接。必要时，编辑器将节点声明留在所属子图，并按原顺序在顶层声明边，再恢复对应的连线样式。无法核实节点归属、连线编号或源码语法时，工具会提示使用源码编辑。

成功重新载入磁盘文件后，提示约 2.5 秒自动收起。仍需处理的只读、磁盘检查错误或外部冲突会继续显示。
