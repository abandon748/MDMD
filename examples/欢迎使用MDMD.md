# 让文字，安静地生长。

欢迎使用 **MDMD**，一款专注于本地 Markdown 文档的阅读与编辑器。

> 打开一份文档，在左侧书写，在右侧看见排版。

## 开始写作

点击「打开文件」选择 `.md` 文件，或按 **Ctrl + N** 新建。按 **F3** 在阅读和分屏编辑之间切换。

### 常用快捷键

| 操作 | 快捷键 |
| --- | --- |
| 打开文件 | Ctrl + O |
| 保存 | Ctrl + S |
| 另存为 | Ctrl + Shift + S |
| 查找 | Ctrl + F |
| 撤销 / 重做 | Ctrl + Z / Ctrl + Y |
| 切换阅读与编辑 | F3 |

## 保留每一次认真修改

- 修改后，标题会显示未保存标记。
- 打开其他文件或关闭窗口时，可以保存、放弃或取消。
- 文件被其他程序修改后，保存会停止，避免覆盖新内容。
- 已有文件保存前的版本保存在同目录 `.mdmd-backups` 文件夹。

## Markdown 的表达

支持标题、**粗体**、*斜体*、~~删除线~~、列表、表格和代码块。

```typescript
const thought = '从一个简单的想法开始';
console.log(thought);
```

1. 记录一个想法。
2. 把它整理成段落。
3. 保存，让下一次写作有迹可循。
