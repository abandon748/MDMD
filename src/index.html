系统集成

MDMD 无需账号或激活。以下设置只影响当前 Windows 用户。右键菜单立即生效；默认应用需在 Windows 中确认。关闭窗口不会撤销已完成的操作。

系统配置绑定当前程序位置。移动或删除 MDMD 前，请先解除关联并删除右键菜单。

配色管理

默认方案只读；复制后可编辑浅色和深色配色。最多保存 20 个自定义方案。

复制、修改和删除在点击“应用”后一起保存，并使用当前所选方案；取消或 Esc 放弃本次改动。请为文字和背景选择清晰的对比色。

自定义 CSS

只作用于阅读／分屏正文，不影响设置和编辑器。使用 h1、p、pre、table 等选择器；正文根节点使用 .markdown-body。支持文字、尺寸、间距、边框等常用排版属性与 @media，不支持外部资源、转义、定位、动画、嵌套选择器和伪元素。

浏览器可能忽略未知属性或修复不完整语法；仅应用识别出的受支持规则。应用会保存，取消／Esc 放弃草稿。清空后应用可移除自定义效果。

选择字体

可选常用名称或输入一个本机字体名。未安装或缺少字符时使用回退字体；不下载字体。
